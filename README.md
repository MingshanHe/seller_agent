# Seller Agent

Seller Agent 是 TikTok Shop 日本跨境 POP 店的 Windows 桌面智能体，用来替代妙手的上架流程，也能处理视频和多个账号。

- **链接上架**：粘贴 1688、淘宝、天猫或拼多多链接，程序会读取商品、写日文文案、处理图片、按成本和日本行情定价，然后生成发布资料。
- **视频**：在飞书或桌面端提供视频，选择“挂车”（关联已上架商品）或“曝光”（不挂车，用来涨粉）。Claude 会写日文文案、话题标签和开头字幕。
- **飞书交互**：发链接、发视频、点卡片按钮都能完成操作。用长连接接入，不需要服务器和公网域名。
- **账号矩阵**：每个账号有独立的浏览器登录状态。店铺号负责上架和挂车，达人号只发曝光视频。
- **出单查货源**：输入 SKU 编码，就能查到 1688 链接和成本。

## 没有 AM 时怎么用

跨境店要有客户经理（AM）才能申请 TikTok Shop 开发者接口，所以程序默认走**半自动模式**：

| 环节 | 程序自动完成 | 需要你做 |
| --- | --- | --- |
| 读取货源 | 用内置浏览器打开链接，读取标题、规格、价格、图片 | 第一次在“货源浏览器”里登录 1688 |
| 文案 | Claude 写日文标题和描述，检查残留中文和站外联系方式 | 看一眼 |
| 图片 | 选主图，可选翻译图上的中文 | 看一眼 |
| 定价 | 成本、佣金、运费、乐天/雅虎行情，按规格算售价和底线价 | 可以改价 |
| 发布商品 | 生成资料包（图片、`listing.txt`、`skus.csv`），提供“复制标题/描述/SKU 表”按钮，并打开该账号的卖家中心 | 在卖家中心粘贴、上传后发布，然后点“我已发布” |
| 视频 | 写文案和话题，打开账号的 TikTok Studio，自动放入视频，文案复制到剪贴板 | 粘贴文案，挂车视频选择商品，点发布 |
| 出单 | 用 SKU 编码查货源链接和成本 | 到 1688 下单 |

拿到 AM 和开发者资格后，在“设置 → TikTok Shop 接口”里填写，并完成店铺授权，就会切到**接口模式**：批准后自动提交商品，出单后自动推送采购卡片。

“发布”这一步刻意不做自动点击。模拟点击卖家中心有封号风险，商品资料最后也应该由人确认。

## 安装

到 [Releases](https://github.com/MingshanHe/seller_agent/releases) 下载 `SellerAgent-Setup-x.y.z.exe`，双击安装。

安装包没有代码签名，Windows SmartScreen 可能会提示风险。点“更多信息 → 仍要运行”即可。

## 第一次使用

1. **设置 → Claude**：填写 API Key，点“测试 Claude”。
2. **账号矩阵**：把默认账号改成你的店铺名称。先用一个账号测试。
3. **账号矩阵 → 登录 1688**：在弹出的浏览器里登录一次。登录状态会保存。
4. **账号矩阵 → 卖家中心 / TikTok Studio**：用这个账号登录一次。
5. **总览**：粘贴一个 1688 链接，大约 1–2 分钟后到“商品上架”查看结果。

以下几项可选：

- **图片翻译**：阿里云百炼的 Key，用来翻译主图上的中文。
- **日本行情**：乐天和雅虎的 App ID。不填时按目标利润率定价。
- **定价参数**：在“设置”最下方修改，包括佣金、运费和利润率。

## 接入飞书（可选）

飞书用长连接接入，电脑开着程序就能收消息，不需要服务器和域名。

1. 在[飞书开放平台](https://open.feishu.cn/app)创建企业自建应用，并开启“机器人”能力。
2. 开通以下权限：`im:message`（收发消息）、`im:message:send_as_bot`、`im:resource`（下载消息里的图片和视频）。
3. **事件与回调 → 事件配置**：订阅方式选“使用长连接接收事件”，添加 `im.message.receive_v1`。
4. **事件与回调 → 回调配置**：订阅方式选“使用长连接接收回调”，添加 `card.action.trigger`。
5. 发布应用版本，把机器人拉进运营群。
6. 在 Seller Agent 的“设置 → 飞书”里填 App ID 和 App Secret，然后保存。
7. 在飞书给机器人发 `id`。它会回复你的 open_id 和群 chat_id，把它们填回设置，再保存一次。

### 飞书指令

| 发送内容 | 结果 |
| --- | --- |
| 货源链接 | 上架到默认账号 |
| `日本店2号 https://…` | 上架到指定账号，按账号名匹配 |
| 商品截图 | Claude 读图后走同样流程，但读不到商品图 |
| 视频 | 弹出卡片，选择挂车或曝光，可填商品 SKU 和运营要点 |
| `货源 SKU编码` | 查货源链接和成本 |
| `状态` | 查看草稿、视频和采购数量 |

关闭主窗口后，程序会最小化到托盘，飞书和取数继续在后台运行。要退出程序，在托盘图标上右键选“退出”。

## 数据放在哪里

- 配置和数据库：`%APPDATA%\Seller Agent\`。密钥用 Windows DPAPI 加密，只能在本机解密。
- 上架资料包：默认 `下载\tts-listings`。
- 视频：默认 `下载\tts-videos`。
- 日志：`%APPDATA%\Seller Agent\logs\app.log`。

不要把数据目录放进 OneDrive 之类的同步盘。SQLite 数据库被同步时可能损坏。

## 开发

需要 Node.js 22.18 或更高版本。

```bash
npm install
npm test            # 129 个测试，不需要任何账号
npm run dev         # 编译并启动桌面程序
npm run dist        # 打包安装程序，输出到 release/
```

不填任何密钥也能查看界面效果：

```bash
node scripts/seed-demo.ts D:\sa-demo
set SELLER_AGENT_HOME=D:\sa-demo && npm start
```

### 发布新版本

1. 修改 `package.json` 里的 `version`。
2. 提交代码，然后打标签并推送：`git tag v0.2.1 && git push --tags`。
3. GitHub Actions 会在 Windows 上测试并打包，再生成一个草稿 Release。确认无误后点发布。

### 目录

```
src/core/            业务引擎（和界面无关，可单独测试）
  app.ts             飞书消息、卡片按钮、取数结果、视频、桌面端操作的总入口
  listing/           上架流程：取数整理、日文文案、选图、半自动资料包
  pricing/           定价引擎、乐天/雅虎行情、汇率
  video.ts           视频文案和飞书卡片
  tiktok/            TikTok Shop 接口（有 AM 后启用）
  feishu/            飞书接口和卡片
src/main/            Electron 主进程
  runtime.ts         把引擎、飞书长连接、取数队列和定时任务接起来
  browser.ts         内置浏览器：货源取数、账号窗口、辅助发视频
  config.ts          配置和密钥加密
renderer/            界面（纯 HTML/JS）
config/pricing.jp.json  默认定价参数
test/                测试
```

## 还没在真实账号上验证的部分

- 飞书长连接的卡片回调返回格式。按 SDK 源码实现，还没在飞书客户端里点过。
- TikTok Studio 上传框的自动放入视频。如果页面结构变了，程序会打开视频所在文件夹，改为手动拖入。
- 1688 真实商品页的取数效果。死链接会被识别并提示，正常商品页还要用登录后的账号实测。
- 日本站定价参数里的佣金和运费，要用第一笔结算明细校准。
